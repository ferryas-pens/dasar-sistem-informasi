Opening story

A number that is correct and already out of date

Course registration day. The screen shows 3 places left. Four minutes later you press save, and the class is already full. Nothing was miscalculated anywhere.

Sequence from the chapter's opening story. The timing of the other students' saves is illustrative; all the story says is that all three happened within those four minutes.

Correct and useful are two different properties. The number three was correct, but it was no longer useful.

Behind the scenes: why doesn't the system keep refreshing the number?

Thousands of students open the same page at the same moment. Refreshing the number every second would flood the system at exactly its busiest hour. So the system settles on a compromise: the number is shown as it was when the page loaded, and it is only confirmed when the save button is pressed. The system gives up timeliness for accessibility. That choice was made by people; it did not happen by itself.

4.6

Information quality is not data quality

Data quality concerns the content of a record. Information quality concerns how useful that record is for a decision. Anyone can check data quality; information quality cannot be checked without knowing which decision it is meant to serve.
